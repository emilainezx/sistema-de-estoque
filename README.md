# Sistema de Gerenciamento de Estoque

## Sobre o projeto

Um sistema de estoque simples rodando no terminal, feito em Node.js.
Desenvolvido como projeto de aprendizado durante meus estudos de JavaScript.

## Funcionalidades

- Visualizar produtos e quantidades em estoque
- Adicionar novos produtos
- Remover produtos existentes
- Exibir o total de itens e o produto com menor quantidade

## Pré-requisitos

Antes de começar, você precisa ter instalado na sua máquina:

- [Node.js](https://nodejs.org/)

## Como executar

Clone o repositório:

```
git clone https://github.com/emilainezx/sistema-de-estoque.git
```
Entre na pasta do projeto:

```
cd sistema-de-estoque
```
Execute o programa:
```
node .
```
